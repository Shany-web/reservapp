# Reservapp

## Descripción
Aplicación web y móvil para gestionar reservas de servicios con pago de abono.

## Objetivo
Automatizar el proceso de reservas, pagos y administración de agendas para profesionales y sus clientes.

## Estado
🚧 En planificación.

## Funcionalidades principales
- Registro de usuarios.
- Reserva de horas.
- Pago de abono.
- Administración de agenda.
- Confirmación de reservas.

## Tecnologías
- Flutter
- Supabase
- PostgreSQL
