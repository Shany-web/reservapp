# MVP (Producto Mínimo Viable)

## Objetivo

Desarrollar una primera versión funcional que permita a un cliente reservar una hora y pagar un abono para confirmar su reserva.

## Funcionalidades

### Usuarios
- Registro de clientes.
- Inicio de sesión.
- Recuperación de contraseña.

### Servicios
- Visualizar servicios disponibles.
- Visualizar profesionales.

### Reservas
- Consultar horarios disponibles.
- Reservar una hora.
- Cancelar una reserva.

### Pagos
- Pagar el abono.
- Confirmar el pago.

### Administración
- Gestionar profesionales.
- Gestionar horarios.
- Ver reservas.

## Fuera del MVP

Estas funciones se desarrollarán en versiones futuras:

- Notificaciones por WhatsApp,correo.
- Programa de fidelización.
- Reseñas de clientes.
- Múltiples sucursales.
- Reportes avanzados.
- Facturación electrónica.
