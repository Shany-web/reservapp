# Casos de Uso

## Actor: Cliente

### CU-01: Registrarse
El cliente puede crear una cuenta en el sistema ingresando sus datos personales.

### CU-02: Iniciar sesión
El cliente puede acceder a su cuenta usando correo y contraseña.

### CU-03: Ver servicios
El cliente puede ver los servicios disponibles con sus precios y duración.

### CU-04: Ver disponibilidad
El cliente puede ver los horarios disponibles de un profesional.

### CU-05: Reservar hora
El cliente selecciona un horario y crea una reserva.

### CU-06: Pagar abono
El cliente paga el abono para confirmar su reserva.

### CU-07: Cancelar reserva
El cliente puede cancelar una reserva según las reglas del negocio.

---

## Actor: Profesional

### CU-08: Gestionar agenda
El profesional puede definir sus horarios disponibles.

### CU-09: Bloquear horarios
El profesional puede bloquear horas o días no disponibles.

### CU-10: Ver reservas
El profesional puede ver sus reservas confirmadas.

---

## Actor: Administrador

### CU-11: Gestionar usuarios
El administrador puede crear, editar o eliminar usuarios.

### CU-12: Gestionar servicios
El administrador puede crear y modificar servicios.

### CU-13: Ver todas las reservas
El administrador puede visualizar todas las reservas del sistema.

### CU-14: Cancelar reservas
El administrador puede cancelar reservas si es necesario.
